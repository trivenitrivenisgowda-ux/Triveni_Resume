# Triveni S — Animated Portfolio (GitHub Pages friendly)

## Files
Keep all these files in the same GitHub repository root:
- index.html
- style.css
- script.js
- triveni-profile.jpg
- ai-data-engineering-analyst.jpeg
- iot-security-analyst.jpeg
- network-security-engineer.jpeg

## Update your existing GitHub repository
1. Download and extract this ZIP.
2. Open your `Triveni_Resume` repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload all 7 files from this folder (select the files, not the outer folder).
5. Commit the changes. If GitHub asks to replace existing files, confirm.
6. Wait a few minutes and refresh your GitHub Pages website with Ctrl+F5.

All image paths are relative to the root folder, so you do not need an `assets` folder. The animated design is preserved.
